Node Remote on a real phone — pairing, status and control, over Tor

Pairing over Tor

Scan the QR, confirm the six digits, done

A Tor v3 onion service with client authorisation. The 6-digit code can only match if both ends hold the same token and address — no account, no server in the middle, no port to forward.

The whole node, in plain language

See it. Steer it.

Height, peers, balance, blend status and the last error — translated from stack trace to sentence. Start and stop the node, wipe the chain database (your keys survive), regenerate the config.

It tells you

Stopped, stalled, no peers, balance moved

Node stopped, node error, sync stalled, no peers, balance changed, block proposed — each one a separate toggle, and notifications can go private so the lock screen shows nothing.

Leader rewards

Claim from the phone, settle on one ledger

The claimable-voucher pool and a permanent claims ledger, shared with the desktop so the two surfaces cannot drift into disagreeing about your money. The button names the cost before the press.
